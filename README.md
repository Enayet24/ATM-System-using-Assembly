# 🏧 ATM System in 8086 Assembly Language

This project is a simple ATM (Automated Teller Machine) simulation written in 8086 assembly language with proper PIN authentication. It is designed to be run on an 8086 emulator like **emu8086**.

## ✨ Features

*   **User Authentication** 🔐: Secure PIN validation for existing users and registration for new users.
*   **Balance Inquiry** 💰: Check the current account balance.
*   **Cash Withdrawal** 💸: Withdraw funds with validation for sufficient balance.
*   **Deposit Money** 💵: Add funds to the account.
*   **Transaction History** 🧾: View the last 5 transactions (deposits and withdrawals).
*   **Undo Last Transaction** ↩️: Revert the most recent deposit or withdrawal.
*   **Log Out** 🚪: Securely log out to allow another user to log in.

## 🚀 How to Run

1.  You will need an 8086 emulator. This code was developed and tested using **emu8086**.
2.  Download the `.asm` file.
3.  Load it into the emu8086 editor.
4.  Compile and run the program!
